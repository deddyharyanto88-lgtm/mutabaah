# Mutabaah Yaumiah

MVP aplikasi pencatatan amalan harian yang berjalan langsung di browser.

## Fitur

- Pilihan jumlah salat wajib yang dilakukan (0–5)
- Input jumlah halaman tilawah per hari
- Checklist dzikir dan sedekah
- Progres dan pesan motivasi otomatis
- Navigasi tanggal sebelumnya/berikutnya
- Catatan refleksi per tanggal
- Unduh summary 7 hari terakhir beserta catatan refleksi dalam format CSV
- Penyimpanan data di `localStorage`
- Tampilan responsif untuk desktop dan mobile

## Menjalankan

Tidak membutuhkan instalasi dependency. Buka `index.html` di browser, atau jalankan server lokal:

```bash
python3 -m http.server 8000
```

Kemudian buka <http://localhost:8000>.
